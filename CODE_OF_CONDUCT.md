# Code of Conduct

This project follows the spirit of the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standards

- Be respectful, patient, and welcoming, especially to first-time contributors.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and its users.
- No harassment, personal attacks, discrimination, or publishing others' private information.

## Enforcement

Maintainers may edit, remove, or reject comments, commits, and issues that don't follow
this code of conduct, and may block participants who repeatedly violate it. To report a
concern, contact the maintainer privately through GitHub
([@no-kap](https://github.com/no-kap)).

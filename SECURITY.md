# Security Policy

## Supported versions

tidytrail is in early development. Only the latest release (or `main`) receives fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Use GitHub's private
reporting instead: open the repository's **Security** tab and choose
**Report a vulnerability**. I'll acknowledge reports as soon as I can and keep you
updated on the fix.

## A note on data

tidytrail processes files locally and never sends data anywhere. It never modifies
your input file; cleaned output goes to a new file. Please don't include real personal
data (student, customer, or employee records) in issues or pull requests.
